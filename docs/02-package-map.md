# 02 — Package map: Ryoku's Arch package sets on Debian / Ubuntu

Scope: every package line in
`system/packages/{base,hardware,dev,aur,cachyos}.packages`, the live-ISO set
`installation/iso/packages.x86_64`, and the `depends`/`makedepends`/`optdepends`
arrays of the three umbrella PKGBUILDs
(`release/packages/ryoku-desktop{,-hyprland,-niri}/PKGBUILD`), at Ryoku commit
`98a0368` (0.75.5-beta.20). That is **354 package lines naming 248 distinct Arch
packages**; every line has a mapping row (one row per distinct name, whose
_Sets_ column cites every line that names it). Arch versions come from the Arch
repo databases (core/extra/multilib, fetched 2026-10-17 from mirrors.kernel.org,
the same data the archlinux.org JSON API serves; the API rate-limited at 429),
the CachyOS repo db, the AUR RPC v5, and the `[ryoku]` PKGBUILDs. Debian/Ubuntu
versions come from `api.ftp-master.debian.org/madison` and Canonical's madison
(the data behind `tools/pkgver`), queried 2026-10-17 including contrib /
non-free / non-free-firmware / universe / multiverse / restricted, re-checked
with the fixed `tools/pkgver` for every name that printed `-`.

Legend for the _Sets_ column: `B` base.packages, `H[x]` hardware.packages
section x, `D` dev.packages, `A` aur.packages, `C` cachyos.packages, `I`
installation/iso/packages.x86_64, `U` ryoku-desktop/PKGBUILD, `UH`
ryoku-desktop-hyprland/PKGBUILD, `UN` ryoku-desktop-niri/PKGBUILD; the number is
the line; `opt` = optdepends, `make` = makedepends. Version cells: `(nff)`
non-free-firmware, `(nf)` non-free, `(contrib)`, `(univ)` universe, `(multiv)`
multiverse, `(restr)` restricted; `-` = not in that suite. In the version
columns, a `|` name in _Debian / Ubuntu pkg(s)_ means the Ubuntu column shows
the Ubuntu name. Version columns show the first Debian name listed; `:i386` rows
show the amd64 version of the same source.

Status meanings (as assigned): SAME = same name, version adequate on at least
one base; RENAMED; SPLIT = one Arch package becomes several debs (or the
reverse); OLDER = exists but too old on every Debian suite; MISSING-BUILD = no
adequate deb, must be built or repackaged (Ryoku-own = one of Ryoku's monorepo
packages); NOT-NEEDED-ON-DEBIAN = Arch mechanism with a named Debian
replacement; REPLACED-BY = Debian equivalent with behaviour differences. Where
adequacy depends on the base, the status says so inline and the row is in the
version-sensitive list.

## Package sets

### Base set (`system/packages/base.packages`)

**What it does:** "The set every machine gets, installed by `pacstrap`"
(system/packages/README.md:9-15); the file header says the installer "pacstraps
this whole set" (base.packages:1-3). 145 package lines.

**Arch couplings:**

- `installation/backend/lib/pacstrap.sh:42-47` reads the file (grep minus
  comments) into the pacstrap list; `:98` `ryoku_ensure_keyring` runs
  `pacman-key --init/--populate archlinux` (`:24-39`); `:130`
  `pacstrap -K /mnt --noconfirm`; `:169-175` online retry
  `--needed --overwrite '*'`; `:103` `genfstab -U`.
- `pacstrap.sh:81-90` appends `broadcom-wl-dkms` when `lspci -d 14e4:` matches
  (Debian: `broadcom-sta-dkms`, non-free; trixie 6.30.223.271-26).
- `installation/backend/lib/preflight.sh:74` reads base.packages for the
  pre-install check; `bin/ryoku-recovery:127` reinstalls it with pacman;
  `installation/tests/iso-preflight.sh:108` lints every `*.packages`.
- `installation/iso/offline-repo.sh:47-55,464-466` resolves base + dev + every
  hardware section (+ cachyos on that variant) into the baked `[offline]`
  file:// repo.
- **Runtime consumer:** `ryoku/cli/internal/ryokumanifest/manifest.go:28-34` +
  `generate.go:14,117-120` embed base/dev/hardware/aur into the release manifest
  that `ryoku doctor` converges every box to (`reconcile_manifest.go`), so these
  Arch names are also read by the CLI at runtime, through pacman
  (`ryoku/cli/internal/sys/sys.go`).
- Hardcoded Arch file paths of packages in this set:
  `ryoku/apps/zsh/ryoku.zsh:45-50` (`/usr/share/zsh/plugins/...`),
  `ryoku/apps/bash/ryoku.bash:18-19` (`/usr/share/blesh/ble.sh`),
  `ryoku/hub/backend/hwcaps.go:574-585` (OVMF paths).

**Arch couplings:**

- Selection: `pacstrap.sh:49-63` maps `RYOKU_PROFILE` → sections: `amd`→[amd],
  `intel`→[intel], `amd-nvidia`→[amd]+[intel]+[nvidia], `vm`→[vm]; anything else
  dies (`:55`). `read_section` (`:10-16`) is an awk INI reader. **Doc/code

  providers (`hardware.packages:12-19`, `pacstrap.sh:122-129`); Debian has no

  for the closure); `ryoku/cli/internal/doctor/reconcile_multilib.go` and

   the rows above (e.g. `xorg-xwayland`→`xwayland`, `bluez-utils`→`bluez`,

   variants.

   and keep the doctor-driven one-time delivery.
3. Hyprland variant: package Hyprland ≥ 0.56 and its plugins built against those
   exact headers; niri variant: build `niri` and `xwayland-satellite` (cargo).
4. Update the duplicated compositor lists in `caps.go` to Debian names.

**Complexity:** High.

**Issues / risks:**

- Hyprland: Ryoku authors its config as Lua (AGENTS.md rule 2); Hyprland's
  `src/config/lua` first appears at v0.55.0 (absent in v0.54.3 and v0.53.3), and

  0.56.2 = Arch.

  `ryoku/hub/quickshell/pages/KeybindsPage.qml:2053`); Quickshell links Qt
  private API, so it must be rebuilt with any Qt rebuild.
- `gpk` (GlazePKG) depends on pacman in the `[ryoku]` recipe; upstream supports
  apt among 46 managers.

## Cross-cutting findings

1. **The package lists are runtime data, not just installer input.**
   `ryokumanifest/generate.go:117-120` folds base/dev/hardware/aur into the
   release manifest (`manifest.go:28-34`) that `ryoku doctor` converges every
   box to; the compositor lists are duplicated in
   `ryoku/wm/hyprland/caps.go:67-78` and `ryoku/wm/niri/caps.go:73-80`;
   `manifest.go:117-133` hardcodes opt-in names (`asusctl`, `dualsensectl`,
   `pam-fprint-grosshack`, `limine-snapper-sync`, `ryoku-palette-bridge`). Any
   Debian rename must flow through all of these, and the doctor's pacman calls
   (`ryoku/cli/internal/sys/sys.go`, `doctor/reconcile_*.go`, `updater/*.go`)
   must target dpkg/apt.
2. **Qt ≥ 6.9** (RectangularShadow) and **Quickshell ≥ 0.3.0** decide the base
   for the shell: forky/sid/resolute have the Qt; only forky/sid package a
   new-enough Quickshell.
3. **Hyprland ≥ 0.56** for the Lua config + plugin keys: only forky/sid; every
   Hyprland plugin (`ryoku-hypr-plugins`, `hyprglass`, `imgborders`,
   `hypr-dynamic-cursors`) must be rebuilt per Hyprland release.
